# NanoDuck 印刷部品

`python ../parts.py` で生成。20 STL、印刷質量 **64 g**(予備・治具を除く)。

> **最初に `fit_coupon_carrier` と `fit_coupon_yoke` だけ印刷してください。**
> 10 分で刷れて、サーボ・ベアリング・M2 ネジの嵌合を全部確認できます。
> ここで合わなければ、それは `../servo_spec.py` の数値が手持ちのサーボと違うという意味で、
> **16 個の構造部品すべてが同じように間違っています。**

## 2. 印刷設定

| | |
|---|---|
| 材料 | **PETG**(PLA 不可 — 関節に実荷重がかかる) |
| ノズル / 層厚 | 0.4 mm / 0.2 mm |
| 外周 | **4**(壁 1.6 mm を前提に設計) |
| 上下面 | 4 層 |
| インフィル | 35 % gyroid |
| サポート | **不要**(サーボポケットは +Y に開口、全オーバーハングが造形面を向く) |
| 配置 | 構造部品は**キャリア底面を造形板に**。層が関節荷重と直交します |

PLA で刷る場合は `../servo_spec.py` の `CLEAR` を 0.25 → 0.15 に下げてください
(PETG の膨張を見込んだ値です)。

## 3. 組立

必要なハード(1 関節あたり):

- M2 タッピングねじ ×2(サーボの耳)
- M2 タッピングねじ ×3(ホーンをヨーク腕へ)
- MR63ZZ ベアリング ×1(3×6×2.5)
- 3 mm ピンまたは M3 ねじ、長さ 8 mm ×1

手順(1 関節):

1. サーボをキャリアに **+Y 側から落とし込む**。耳が座に密着すること
2. 耳を M2 タッピング ×2 で締める。締めすぎるとボスが割れます
3. MR63ZZ をヨークの **−Y 腕**に圧入
4. ホーンをヨークの **+Y 腕**の座に落とし、M2 タッピング ×3 で固定
5. ホーンをサーボのスプラインに嵌め、付属の中心ねじで留める
6. 3 mm ピンをキャリア底面の穴からベアリング内輪へ通す

**必ずサーボを中立位置に合わせてからホーンを嵌めてください。** ホーンは 18° 刻みでしか
噛まないので、ずれると可動域の非対称(下記)が逆側に出ます。

## 4. 可動域は「実測値」です

`parts.py --check` が各関節を掃引し、子のヨークが親のキャリアに当たる角度を
ブーリアン交差で測っています。レンダリングでは絶対に見えません。

| 関節 | 可動域 | ホーム位置 |
|---|---|---|
| hip_pitch | **−32.5° 〜 +100.0°** | +11.5° |
| knee | **−102.5° 〜 +32.5°** | −22.9° |
| ankle | **−10.0° 〜 +22.5°** | +11.5° |

非対称なのはサーボ本体が前後の片側に張り出しているためです。
**膝キャリアだけ X 反転**してあり、広い 100° 側が実際に膝が曲がる向きに来ています
(反転前はホーム −22.9° に対し限界 −25°、余裕 2° しかありませんでした)。

これらは `../build_nanoduck.py` の `JOINTS` にそのまま入っていて、
MJCF の関節リミットになります。**機構が回らない角度を学習させないため**です。

> ⚠️ **足首の 32° が現状いちばん厳しい制約**です。歩容を縛るはずなので、
> 機構側で次に直すならここです。

  当てずっぽうで置いたら「それらしく見えて間違っている」結果になったので外しました
