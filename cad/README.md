## 先に読むこと — MG90S は「入らない」

```bash
python check_servo_fit.py
```

**MG90S は小さいサーボではない。薄いサーボである。**

| | 長さ | 高さ | 幅 | 質量 |
|---|---|---|---|---|
| XL330-M288 | 34.0 mm | 29.0 mm | 20.0 mm | 18.0 g |
| MG90S(耳込み) | 32.2 mm | 28.5 mm | 12.2 mm | 13.4 g |
| 比 | **0.95** | **0.98** | 0.61 | 0.74 |

よく言われる「MG90S は XL330 の 45 % の体積」は事実だが**完全にミスリード**。
連鎖方向の長さが制約なので、効くのは体積ではなく長さで、そこは **5 % しか縮んでいない**。

### なぜ「リンク長 ≥ サーボ長」では判定できないか

MicroDuck の股関節は 3 DOF を 71 mm の連鎖に収めている = **サーボ1個あたり 23.7 mm**。
XL330 は 34 mm なので、既にサーボ同士が 43 % 重なっている。
多自由度クラスタでは「入るか」ではなく**実装密度**で見るしかない:

```
実装密度 = サーボ長 ÷ (連鎖長 ÷ サーボ数)
```

| クラスタ | 連鎖 | 数 | mm/個 | MicroDuck 実績 | NanoDuck s=0.56 で必要 |
|---|---|---|---|---|---|
| 股 (yaw+roll+pitch) | 71.0 mm | 3 | 23.7 | 1.44 | **2.43** |
| 頭 (pitch+yaw+roll) | 73.7 mm | 3 | 24.6 | 1.38 | **2.34** |
| 腿→膝 | 42.2 mm | 1 | 42.2 | 0.81 | 1.36 |
| 脛→足首 | 49.4 mm | 1 | 49.4 | 0.69 | 1.16 |

**s=0.56 では MicroDuck が実証済みの密度の 1.7 倍が要る。**
これは幾何の問題なので、再学習でもギヤでも動かない。

### 制約が交差している

```
幾何:   MicroDuck と同じ実装密度を守るなら s ≥ 0.95(237 mm)= ほぼ縮まない
トルク: MG90S @6.0V が成立するのは s ≤ 0.56(140 mm)
                            ↑ 重ならない
```

**ここが NanoDuck の本丸**。トルクではなく実装が律速。

### 抜け道(安い順)

1. **DOF を減らす** — 一番きつい頭部クラスタ(pitch+yaw+roll が 24.6 mm/個)は
   歩行に不要。`head_yaw` と `head_roll` を落として 14 → **12 DOF**。
   再学習はどのみち必須なので、14 アクション契約を守る理由はない
2. **サーボを混ぜる** — 首・頭は s=0.56 換算で 0.018–0.025 Nm しか要らない
   (膝は 0.12 Nm)。3.7 g マイクロサーボで十分で、場所が空く
3. **遠隔駆動** — 膝・足首のサーボを胴体に移してリンク機構で駆動する。
   200 mm 以下の二足では定石。脚の体積が丸ごと空く。代償はバックラッシだが、
   これは `add_backlash.py` で既にモデル化されている

v1 BOM は 1 + 2 を採用している([../bom/README.md](../bom/README.md))。
3 は股関節が 12 DOF でもまだ密なので、いずれ必要になる可能性が高い。

## scale_meshes.py

```bash
python scale_meshes.py --scale 0.50
```

バイナリ STL を一様スケールする。一様スケールでは面法線は不変(単位ベクトル)なので、
三角形あたり 9 個の頂点 float だけを触る。スケール比は検証済み(実測 0.500)。

**これは形状確認とシム用**であって完成した機械設計ではない。スケールしないものが3つある:

- **サーボ座**: 全部 XL330 (29×20×34) 用に彫られている。MG90S は出力軸が片側のみで
  耳が横に出る、まったく別のインタフェース。全部引き直し
- **肉厚**: 0.5 倍は 2 mm の壁を 1 mm にする。FDM で出しにくい上に荷重的に足りない。
  肉厚は「絶対値」で戻すもので、スケールするものではない
- **買う部品**: ベアリング・ネジ・電池は実寸のまま。M2 は M2 のまま、
  MicroDuck の 22×16×4 ベアリングは MR63/MR83 になるのであって
  11×8×2(存在しない)にはならない
